# Задание. Настроить клиентские и серверные механизмы оптимизации в Angie для повышения производительности веб-приложения.
____________________________________________________________________________________________________________________
##  Шаги выполнения
1. Выполнить настройки клиентской оптимизации
2. Настроить серверное кэширование одной страницы
3. Провести тест сайта до и после оптимизации
___________________________________________________________________________________________________________________
### Описание стенда
Host_VM: 
Docker container:
 - webserver. На нем развернут angie, конфигурационные файлы находятся на хосте
   в папке ~/angie, и проброшены во внутрь контейнера
- db. Контейнер для работы базы данных Mysql, необходимой для wordpress
- wordpress. Представляет backend, с помощью него создан сайт с 3-мя страничками для тестов.
- prometheus. Контейнер для сбора метрик с angie.
- grafana. Для наглядности работы angie
- renderer. Для прорисовки dashbord в grafana.</br>
